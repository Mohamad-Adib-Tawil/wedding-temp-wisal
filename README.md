# Wedding Invitation — Wisal

Static Arabic wedding invitation based on the supplied Wisal template files.

## Edit invitation details

Edit `invitation.config.js` to update the couple names, event date and time, venue, map, program, notes, WhatsApp destination, music video, and asset paths. The page is designed for GitHub Pages and uses relative local asset paths.

The RSVP form prepares a WhatsApp message addressed to the configured number. It does not store guest responses because GitHub Pages is static hosting.
